# Contributing

Thank you for improving Link Analytics.

1. Fork the repository and create a focused branch from `main`.
2. Install dependencies and configure `.env` from `.env.example`.
3. Keep business logic in services and database access in repositories.
4. Add or update meaningful tests for behavior changes.
5. Run `npm run build`, `npm run lint`, `npm run format:check`, and `npm test`.
6. Open a pull request explaining the problem, solution, and validation performed.

Never commit credentials, `.env`, production data, or personal click data. By contributing, you agree that your work is licensed under the MIT License.
